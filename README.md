# Multi-Page Portfolio — React Router Practice

Build a 4-page portfolio site with React Router v7. Practice file-based routing, NavLink active states, and multi-page navigation.

## Quick Start

```bash
git clone https://github.com/LoisBN/fpp-portfolio-routes.git
cd fpp-portfolio-routes
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to see the app.

## Project Structure

```
app/
├── routes/           ← Create your page components here
├── data/             ← Project data
├── root.tsx          ← App shell (put your Navbar here)
└── routes.ts         ← ⭐ Define your routes here
```
